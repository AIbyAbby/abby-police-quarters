# 走進消失ing的警舍街角

新店七張警察眷舍與仁愛里社區發展文化地圖與田野紀錄獨立網站。

## 網站介紹
本網站收錄新店七張警察眷舍的歷史變遷、時間軸、社區走讀紀錄、老照片比對、街訪故事與植物圖鑑等共 16 篇珍貴圖文紀錄。

## 部署說明
已支援 GitHub Pages 靜態網站發布。
在儲存庫的 **Settings -> Pages** 中，將 Branch 設為 `main`、目錄設為 `/ (root)` 即可自動上線。
